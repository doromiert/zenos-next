## Omissions To Resolve

- **ISO path hiding:** `B:profiles/installer-iso.nix` added `iso`, `iso-config` and `iso-config-template` to hidden root entries. Current ZenFS runtime has only the generic FHS list, with no live additions. Decide the current declaration and check Nautilus's root view.
- **Locked GNOME defaults:** baseline locked `disable-user-extensions` and `favorite-apps`; current appearance declares values but not those locks. Decide whether editability is intentional, then test actual dconf writability.
- **Boot handoff and identity:** baseline explicitly enabled Bluetooth, initrd `virtio_gpu`, `vt.global_cursor_default=0`, Plymouth `quit --retain-splash`, and a revision-bearing release/ISO label. These are not explicitly carried into the reviewed composition/hooks. Check inherited effective values and actual boot/session behavior before declaring a regression or parity; current release text is fixed `1.0.0Nb`.
- **Do not expand baseline accidentally:** `gnome-profile.nix` was imported indirectly but disabled for the baseline ISO. Its lock-screen branding and full shortcut profile were not active live behavior. Hardware/ZeroBridge/XR/maintenance/Janitor modules were also opt-in, not enabled ISO services. Reusable capability restoration beyond the active image needs its own acceptance.
- **Documentation is not a completed integration:** older installer/appearance/live-config handoffs contain pre-wiring statements and earlier counts. This matrix records the reviewed source and supplied results; only the parent agent's full-image and real-GUI evidence can close the remaining acceptance rows.
